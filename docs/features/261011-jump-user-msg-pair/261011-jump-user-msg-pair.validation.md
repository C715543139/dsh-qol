# 上一条/下一条用户消息连体按钮 用户验证

## 验证说明

- 验证对象：右下角「回到底部」上方的新连体按钮（设置 → QoL → 导航与切换 → 「上一条/下一条用户消息」开关，默认开）
- 环境/前置条件：手机访问 dsh Web（插件 dsh-qol 已加载，**刷新页面生效**）；当前会话已有 ≥3 条用户消息、内容超一屏可滚动
- 注意：改动只在本地 `lib/`，线上 4180 实例刷新页面即可生效（client bundle 按需读盘）

## 验证项

| # | 验证步骤 | 预期结果 | 实际结果 | 状态 |
| --- | --- | --- | --- | --- |
| 1 | 进入长会话，向上滚动离开底部 | 右下角出现**竖立连体按钮**（上半 ↑、下半 ↓，中间一道细线），位于宿主「回到底部」按钮上方约 8px；右边缘与「回到底部」对齐；「回到底部」仍是**独立**的圆形按钮 | 实机确认 | 通过 |
| 2 | 连点上半（↑） | 每次上跳到上一条用户消息并把该条顶对齐（顶部留约 16px），逐条上溯；到第一条后再点停住/翻到最顶；在消息间距很小或刚好临界的位置也不能出现“点了无反应” | 实机确认 | 通过 |
| 3 | 连点下半（↓） | 每次下跳到下一条用户消息并顶对齐；当前消息只在视口顶部下方约 30~50px 时，也必须直接跳到真正的下一条，不能只做一小段几乎看不出的微移；宿主标记为 `steering` 的用户消息也不能被跳过；到末尾再回到底部 | 实机确认，包含「我希望」这条临界位置 | 通过 |
| 4 | 在底部附近**来回小幅滚动**（宿主「回到底部」按钮反复出现/消失） | 连体按钮**始终停在同一个位置，不跳变**；宿主按钮出现时在它下方 8px 处，宿主按钮不在时连体按钮原地不动 | 实机确认 | 通过 |
| 5 | 设置里关闭「上一条/下一条用户消息」 | 连体按钮整体消失；宿主「回到底部」不受影响 | 实机确认 | 通过 |

## 验证结论

用户于 2026-10-11 实机确认：「看起来搞定了。」五项核心场景均通过；第 3 项包含此前失败的「我希望」临界位置。
