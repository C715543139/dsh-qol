# tabbar-width 验证

## 验证说明

- 验证对象：标签尺寸放大 + Chrome 式自适应宽度 + 取消 12 标签上限 + 关闭延迟重排（触屏立即重排）+ 移动端 72px 下限
- 环境：Windows 11 + dsh 0.2.1-rc.3；桌面端手测，另起临时 `dsh --profile web` 实例做 390×844 触屏视口验证
- 方法：临时实例用 `dsh plugin --profile web add link:<repo>` 挂本仓库；浏览器经 CDP 设 390×844 / DSF 3 / touch，标记数量用 `dsh.qol.opentabs` 预置控制
- 注意：本次改动不在 npm 已发布版本里，验证用的是本仓库 `lib/client.js`

## 文本宽度的取舍

72px 下标签的固定开销约为 56px（左右内边距 24 + 状态点与间距 12 + 关闭按钮与间距 20），所以早期版本只剩约 16px 文本，实测只显示「一个字 + …」。改为**非活动标签不显示 ×** 后，文本宽度回到 36px；活动标签仍保留 ×（20px 文本）。触屏没有 hover，因此点一下先激活、再点 × 关闭；中键与右键菜单仍可直接关闭。

## 验证结论

功能行为全部符合预期：自适应宽度、72px 移动端下限、取消数量上限、鼠标延迟重排、触屏立即重排，以及非活动标签隐藏关闭按钮均按设计工作。
